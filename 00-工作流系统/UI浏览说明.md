# 本地控制台怎么用

本地控制台是只读工作台。它帮你看求职状态、岗位、报告和 Agent runs，不替你批准投递，也不直接改外部平台。

## 打开

第一次先装依赖：

```bash
cd console
npm install
cd ..
```

然后双击根目录：

```text
打开本地求职控制台.command
```

或运行：

```bash
./00-工作流系统/local-control/start.sh
```

浏览器访问 `http://127.0.0.1:8788`。

## 页面

- **检索岗位**：看最近检索到的岗位。可搜索公司或岗位，切换检索日期。点击报告会在新标签页打开，列表留在原页面。
- **总览**：看当前目标、投递计数、待决定候选、下一步和阻塞。
- **投递**：看已准备、已提交、已验证、面试中和已结束的岗位。
- **报告**：集中打开岗位报告、批次报告、巡检记录和面试材料。
- **跟踪中**：看仍需回读的平台状态和跟进项。
- **更多**：看 Agent runs、长期记忆、执行记录等技术视图。

## 报告打开方式

HTML 报告默认在新标签页打开。控制台会保留当前筛选和列表位置。

“已打开”只表示当前浏览器打开过这个报告版本，不代表已读完、已审核或同意投递。

## 数据来源

控制台读取 `jobflowd`，再由 `jobflowd` 读取仓库里的结构化状态和生成视图。

它不读取浏览器密码，不保存平台 Cookie，不直接修改招聘平台。

## 看到“没读到”

通常是 `jobflowd` 没启动，或控制台没有拿到启动脚本生成的 token。

请用根目录启动脚本打开控制台，不要直接在 `console/` 里跑 `npm run dev`。如果仍然失败，先运行：

```bash
python3 00-工作流系统/bin/jobflow.py validate
```
