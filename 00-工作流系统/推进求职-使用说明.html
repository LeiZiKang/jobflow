返回推进求职

你只需要决定机会和确认发送内容

平时打开本地求职控制台。首页先看检索岗位，报告在新标签页打开。需要推进时再看“推进求职”。

Agent 负责核实岗位、整理材料、更新状态。你负责决定投哪里、发什么，以及处理登录、验证码和最终提交。

平时怎么开始

直接对 Agent 说：

按推进求职页处理今天能做的事。先看已有回复，再准备已批准岗位；需要我决定时给我具体材料。

Agent 会读取仓库并同步下一步。页面是生成快照，状态更新后会刷新。

四类工作

  • 推进已有机会：核实已投岗位回复，为已批准岗位准备文字和附件。
  • 检索新岗位：只读收集岗位，去重，形成候选草稿。
  • 等待你决定：只问具体岗位。批准岗位后，最终发送文字和附件仍需再确认。
  • 运行检查：核对检索、跟进和定时任务是否真的跑过，不把“没查成”写成“没有机会”。

怎样批准

看完 Agent 提供的岗位链接、平台、发送文字和附件版本后，明确批准哪一份。修改文字、换岗位或换附件，都需要重新确认。

批准记录会绑定具体内容，不会扩到别的公司或岗位。

看到受阻

登录、验证码、凭据输入、平台要求你本人确认时，Agent 会停下并说明停在哪里。你完成后，让它继续原任务。

没有平台成功证据，就不会把投递写成已验证。

边界

系统会整理下一步与保存执行结果，但不会凭空读取平台、自动同意条款或发消息。平台协议、账号风险和最终决定由你负责。
