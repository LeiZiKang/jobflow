# Runbook：Claude / Codex 运行时切换

1. 记录当前 task ID、最后成功状态和 blocker；不要把这些只留在聊天里。
2. 如果原 Decider 租约仍有效但账号不可用，等待租约过期或由用户明确授权接管。
3. 新 backend 启动全新 session，不传入上一 session 全文。
4. 使用 `jobflow.py bootstrap-prompt --role decider` 作为第一条指令。
5. 新 Decider 完成 validate/status/next，并向用户复述当前状态。
6. 只读核实中断前的最后一个外部动作，避免重复发送或重复投递。
7. 接管后更新 Active Decider、事件日志和 brief。

如果某 backend 缺少审批桥，必须按 `backend_capabilities.json` 降级为只读；不能因为切换账号而放松审批。
