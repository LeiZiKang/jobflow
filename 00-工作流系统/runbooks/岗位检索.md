# Runbook：岗位检索与背调

1. 从 `current.json`、`decision_index.json` 和任务信封取得当前目标与硬线。
2. 先查去重与已否决记录；时效没有变化时不重复完整背调。
3. 检索阶段默认只读，不投递、不沟通、不收藏。
4. 每条候选逐条打开 JD 原文，记录链接、抓取时间、地点、薪资、年限和英语原文。
5. 区分十秒硬线、简历缺口、WLB 未知和需要电话确认的问题。
6. 公司背景记录主体、规模/参保、融资/上市、团队与 WLB 来源；查不到如实写。
7. 输出候选时同时给：事实、推测、优势、缺口、建议和置信度。
8. Decider 评审后才能进入 `awaiting_user_decision`。
