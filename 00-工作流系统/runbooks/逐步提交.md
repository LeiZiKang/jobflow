# 逐步提交

适用于用户要求“每一步更改都单独 git commit”的会话。

本会话按以下方式执行：

1. 每完成一个可独立验证的改动，连同该步骤必要的测试、说明和证据一起提交，再进入下一项改动。
2. 提交前检查暂存区，只包含当前步骤；不把用户原有暂存、未暂存或未跟踪内容扫入提交。
3. 共用文件有混合改动时，按备份和差异暂存对应内容，不为方便而覆盖工作树。
4. 必需的旧基线不属于本会话时，先给出具体范围；得到明确允许后，将它作为单独的基线提交，保留来源。
5. 不伪造已经过去的提交时刻。本次补提交使用当前时间，提交说明对应真实功能阶段。
6. 正常执行适用检查和 Git hooks，不绕过校验。不因一个提交后提示失败就误称 Git commit 失败，应回读实际 commit。

此文件记录当前用户指令；长期记忆仍通过 memoryctl 以 proposed 提出，不由 Agent 自行接受。
